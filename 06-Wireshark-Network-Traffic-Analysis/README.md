# 📌 Project Overview

Wireshark is one of the most widely used network protocol analyzers for troubleshooting, monitoring, digital forensics, and cybersecurity investigations.

This project demonstrates practical network traffic analysis using Wireshark by capturing, filtering, and inspecting packets exchanged across a network. The investigation focuses on understanding communication between hosts, identifying protocols, analyzing network behavior, and recognizing suspicious activities from captured traffic.

The project follows industry-standard network forensic methodologies and showcases practical skills used by SOC analysts, network security engineers, and digital forensic investigators.
