# 📌 Project Overview

Network reconnaissance is the foundation of every security assessment. Before vulnerabilities can be identified or exploited, it is essential to understand the target environment.

This project demonstrates how Nmap can be used to perform safe and structured network reconnaissance by identifying live hosts, scanning open ports, detecting running services, fingerprinting operating systems, and gathering valuable network intelligence.

The project follows ethical hacking principles and highlights how reconnaissance supports vulnerability assessments, penetration testing, and defensive security operations.
