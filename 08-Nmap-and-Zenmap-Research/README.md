# 📖 Project Overview

Understanding a network is the first step in securing it.

This research project explores two widely used network scanning tools—**Nmap** and **Zenmap**—to understand their capabilities, differences, and practical applications in cybersecurity.

The project combines theoretical concepts with practical demonstrations to compare command-line scanning using Nmap and graphical analysis using Zenmap. It highlights how both tools assist cybersecurity professionals in reconnaissance, vulnerability assessment, and network security auditing.
