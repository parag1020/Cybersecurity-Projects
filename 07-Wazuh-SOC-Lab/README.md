# 📌 Project Overview

Modern organizations require continuous monitoring to detect cyber threats before they become security incidents.

This project demonstrates the deployment and practical use of the **Wazuh Security Platform** to monitor endpoint activities, collect security logs, analyze suspicious events, and investigate potential threats within a controlled enterprise environment.

The lab simulates the daily responsibilities of a Security Operations Center (SOC) analyst by integrating endpoint monitoring, log collection, rule-based detection, alert generation, and incident investigation into a complete defensive security workflow.
