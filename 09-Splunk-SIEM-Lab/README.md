# 📌 Project Overview

Security teams generate millions of security events every day, making centralized log analysis essential for identifying threats efficiently.

This project demonstrates the implementation of **Splunk Enterprise** as a Security Information and Event Management (SIEM) platform to collect, index, search, correlate, and visualize security events from multiple sources.

The laboratory simulates real-world Security Operations Center (SOC) activities including log ingestion, dashboard monitoring, threat detection, SPL query analysis, and security incident investigations.
