# 📌 Project Overview

Open Source Intelligence (OSINT) plays a critical role in modern cybersecurity investigations by transforming publicly available information into actionable intelligence.

This project demonstrates a structured OSINT investigation inspired by professional research methodologies used by organizations such as Citizen Lab and Bellingcat. The investigation focuses on collecting, validating, correlating, and documenting information from open sources while maintaining accuracy, transparency, and ethical standards.

The project highlights how cybersecurity professionals use publicly available data to support digital investigations, threat intelligence, and security assessments without relying on unauthorized access or intrusive techniques.
